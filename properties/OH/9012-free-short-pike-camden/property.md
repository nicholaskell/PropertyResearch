## Zoning / Development
Preble County's current zoning code contains multiple rural districts with very different split rules. For example, RR requires 2 acres and 200 ft frontage; RR-1 generally requires 1 acre and 150 ft width without sewer; Agricultural zoning can require 40 acres/300 ft width except limited homestead-split situations. Therefore the MLS label “Residential, Agricultural” is insufficient to estimate lot count. Official Land Use Management confirmation is required before assigning subdivision value.

County code generally limits a parcel to one primary structure unless specifically allowed elsewhere. A future Thomas homesite therefore likely requires a lawful lot split or another expressly allowed dwelling path.
